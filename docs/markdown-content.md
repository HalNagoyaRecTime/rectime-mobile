# 通知詳細・イベント説明のMarkdown

本文の保存形式は文字列ひとつです。通知詳細とイベント説明は装飾の有無を判定せず、共通のAppMarkdownで表示します。普通の文章もそのまま入力できます。

- 単独改行は段落内の空白として扱います。
- 行末の空白2個以上＋改行、またはバックスラッシュ＋改行で強制改行します。
- 空行で段落を区切ります。
- 字下げ、行末空白、先頭・末尾の改行をAPIと管理画面で削りません。
- 見出し・リスト・表・コード・HTTP(S)画像を使えます。画像の共通キャッシュと拡大ビューアは従来どおりです。

APIで削られた過去の空白は自動復元できません。APIの空白保持対応をマージ・反映してから、この表示仕様を使います。format列・バージョン分岐・旧形式判定は追加しません。
